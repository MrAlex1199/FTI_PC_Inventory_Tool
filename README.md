# FTI PC Inventory Tool

โปรแกรมตรวจสอบและบันทึกข้อมูล **Hardware** และ **Software ที่ติดตั้ง** ของเครื่อง PC ในโดเมนองค์กร (~200 เครื่อง) ในรูปแบบหน้าต่าง **Windows GUI** มาตรฐาน (.exe) ใช้งานง่าย รองรับการออกรายงานเป็นไฟล์ **CSV** และ **HTML แบบแยกกล่องรายเครื่อง**

---

## 🌟 ฟีเจอร์เด่น
1. **Modern Cyber Slate Glassmorphism UI**: หน้าต่างแอปสไตล์กระจกเงาคมชัด รองรับทั้ง Dark Mode และ Light Mode พร้อมแอนิเมชัน SVG วงแหวนความคืบหน้า (Progress Ring) และการ์ดสถิติเรืองแสง 4 มิติ
2. **เครื่องมือติดตามผลลัพธ์สด (Live Results Data Grid)**: แสดงสถานะและสเปกเครื่องที่ตรวจพบแบบ Real-time พร้อมช่องค้นหาด่วน (Instant Search) และปุ่มกรองสถานะ (ทั้งหมด / สำเร็จ / ออฟไลน์ / มีข้อผิดพลาด)
3. **คอนโซลเทอร์มินัลพับเก็บได้ (Terminal Drawer)**: ติดตามข้อความและสเต็ปการทำงานเบื้องหลังได้อย่างละเอียด
4. **ไม่ค้างระหว่างสแกน (Multi-threaded Async Engine)**: หน้าต่างโปรแกรมลื่นไหล 60fps ตอบสนองได้ตลอดเวลา และสามารถกดยกเลิกการสแกนได้ทันที
5. **แหล่งรายชื่อเครื่องยืดหยุ่น**:
   - ดึงรายชื่อเครื่องจาก **Active Directory (AD)** อัตโนมัติ (กรองเฉพาะเครื่องที่ Login ภายใน N วัน หรือตัวกรองชื่อเครื่อง)
   - ระบุไฟล์รายชื่อเครื่องเฉพาะเจาะจง (`.txt` บรรทัดละ 1 เครื่อง)
   - สแกนเฉพาะเครื่องตนเอง (**Localhost**) สำหรับการทดสอบ
6. **ความแม่นยำและรวดเร็ว**:
   - **WinRM (ขนาน)**: สแกนซอฟต์แวร์หลายเครื่องพร้อมกันด้วยความเร็วสูง
   - **DCOM Fallback**: สลับไปใช้ CIM/DCOM ทีละเครื่องอัตโนมัติหากเครื่องปลายทางไม่ได้เปิด WinRM
   - **Hardware Scan**: สแกนยี่ห้อ/รุ่น, Serial, CPU, Cores, RAM, Disk, GPU, OS, IP, MAC Address
7. **รายงานผลลัพธ์ครบวงจร**:
   - ออกรายงาน HTML Interactive สวยงาม เปิดอัตโนมัติเมื่อสแกนเสร็จ พร้อมไฟล์ CSV ครบทุกมุมมอง

## 📁 โครงสร้างโปรเจกต์

```text
FTI_PC_Inventory_Tool/
├── src/
│   ├── Get-PCInventory.Core.ps1   # ตรรกะการสแกนหลัก (คงเดิม 100% ไม่ถูกดัดแปลง)
│   ├── AppServer.ps1              # เอนจิน HTTP Server เบื้องหลัง + เชื่อมต่อ Edge App
│   └── web/
│       └── index.html             # ส่วนติดต่อผู้ใช้ Cyber Slate Glassmorphism (HTML5/CSS/JS)
├── build.ps1                      # สคริปต์รวมโค้ดและคอมไพล์เป็น .exe ตัวเดี่ยวด้วย PS2EXE
├── run.bat                        # สคริปต์คลิกเดียวสำหรับเปิดโปรแกรมทันที
├── dist/                          # โฟลเดอร์สำหรับวางไฟล์ .exe
└── README.md                      # คู่มือการใช้งาน
```

## 🚀 วิธีการใช้งาน

### วิธีที่ 1: เปิดใช้งานผ่าน `run.bat` (สะดวกที่สุด)
- ดับเบิ้ลคลิกไฟล์ `run.bat` ในโฟลเดอร์โปรเจกต์ โปรแกรมจะเรียกใช้งานแอปพลิเคชันขึ้นมาทันที

### วิธีที่ 2: นำไฟล์ `.exe` ไปใช้งานแบบ Standalone
- ก๊อปปี้ไฟล์ `FTI_PC_Inventory.exe` (จากโฟลเดอร์ `dist` หรือ `%TEMP%`) ไปวางไว้บนเครื่อง Admin, Desktop หรือ USB Flash Drive
- คลิกขวาที่ไฟล์ `FTI_PC_Inventory.exe` แล้วเลือก **Run as administrator** (ใช้บัญชี Domain Admin)

### ขั้นตอนการสแกนในโปรแกรม:
1. **เลือกแหล่งรายชื่อเครื่อง**:
   - *Active Directory (Domain)*: สแกนทั้งระบบ เหมาะสำหรับสแกนรอบใหญ่ทั้งองค์กร
   - *จากไฟล์ข้อความ (.txt)*: ระบุไฟล์รายการชื่อเครื่องที่ต้องการสแกน
   - *เครื่องนี้เท่านั้น (Localhost)*: เหมาะสำหรับทดสอบการทำงานของระบบ
2. **กำหนดตัวเลือกเพิ่มเติม**:
   - ติ๊กเลือกข้อมูลที่ต้องการ (ฮาร์ดแวร์ / ซอฟต์แวร์ / ซอฟต์แวร์ระดับผู้ใช้)
   - ปรับจำนวน Threads สแกนขนาน (แนะนำ 10-20 เครื่องพร้อมกัน)
   - ระบุโฟลเดอร์ปลายทาง (ค่าเริ่มต้น `C:\Inventory`)
3. **กดปุ่ม "เริ่มสแกนทันที"**:
   - ติดตามความคืบหน้าจากวงแหวน Progress Ring, ตัวเลขสถิติ 4 ใบการ์ด และตารางข้อมูล
4. **เปิดดูรายงาน**:
   - เมื่อสแกนเสร็จสิ้น ระบบจะเปิดหน้ารายงาน HTML ในเบราว์เซอร์ให้อัตโนมัติ หรือกดปุ่ม "เปิดรายงาน HTML ล่าสุด" ได้ทันที

## 🛠️ วิธีการ Build เป็น .EXE (สำหรับ Developer / Admin)

หากต้องการคอมไพล์ใหม่หลังแก้ไขโค้ด:

1. เปิด PowerShell แบบ **Run as administrator**
2. ไปที่โฟลเดอร์โปรเจกต์:
   ```powershell
   cd E:\WEB\FTI_PC_Inventory_Tool
   Set-ExecutionPolicy -Scope Process Bypass
   ```
3. สั่งรันสคริปต์ Build:
   ```powershell
   .\build.ps1
   ```
4. ระบบจะ:
   - ตรวจสอบและเตรียมโมดูล `ps2exe`
   - สร้างไอคอน Vector Squircle บรรจุลงไฟล์
   - รวม `Core.ps1` และ `Gui.ps1` เข้าด้วยกันแบบ Base64 (ป้องกันปัญหา Encoding)
   - คอมไพล์ออกมาเป็นไฟล์ `FTI_PC_Inventory.exe` (พร้อม Manifest Require Administrator + DPI Aware)

## 📋 ไฟล์ผลลัพธ์ที่ได้รับ (ใน `C:\Inventory`)

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| `Hardware_<วันเวลา>.csv` | ข้อมูลสเปกเครื่อง: ยี่ห้อ, รุ่น, Serial, CPU, RAM, Disk, GPU, OS, IP, MAC |
| `Software_<วันเวลา>.csv` | รายละเอียดซอฟต์แวร์ทั้งหมดที่ตรวจพบในทุกเครื่อง |
| `Software_Summary_<วันเวลา>.csv` | สรุปแต่ละโปรแกรมและเวอร์ชันว่ามีติดตั้งอยู่กี่เครื่อง |
| `Software_PerPC_<วันเวลา>.csv` | สรุปรายชื่อโปรแกรมทั้งหมดของแต่ละเครื่อง (1 แถวต่อ 1 เครื่อง) |
| `Software_ByPC_<วันเวลา>.html` | รายงานเว็บสวยงาม แยกกล่องค้นหารายเครื่อง เปิดใน Chrome/Edge ได้ทันที |
| `Software_ScanStatus_<วันเวลา>.csv` | สถานะการสแกนของแต่ละเครื่อง (`OK-WinRM`, `OK-DCOM`, `Offline`, `Error`) |

## ℹ️ ข้อสังเกตและวิธีแก้ปัญหา
- **สิทธิ์การทำงาน**: โปรแกรมจำเป็นต้องรันด้วย Domain Admin เพื่อให้สามารถเชื่อมต่อไปยัง CIM/WMI และ Registry ของเครื่องลูกข่ายได้
- **Windows Defender (Controlled Folder Access)**: หากเปิดใช้งานฟีเจอร์นี้บน Windows แนะนำให้เพิ่ม `FTI_PC_Inventory.exe` เข้าในรายชื่อ Allowed Apps เพื่อให้โปรแกรมสามารถบันทึกไฟล์รายงานลงโฟลเดอร์ผลลัพธ์ได้อย่างราบรื่น
