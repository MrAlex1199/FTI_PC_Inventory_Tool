01
ความเป็นมา & ปัญหาที่พบ Background & Problem Statement

บริษัท ฟังก์ชั่น อินเตอร์เนชั่นแนล จำกัด (Function International - FTI) มีทุนจดทะเบียน 225 ล้านบาท ดำเนินธุรกิจการผลิต นำเข้า และขายส่งผลิตภัณฑ์ที่เกี่ยวกับน้ำอย่างครบวงจร ภายในองค์กรมีเครื่องคอมพิวเตอร์ลูกข่ายในระบบเครือข่าย Active Directory มากกว่า 200 เครื่อง กระจายตามฝ่ายงานและคลังสินค้า การบริหารจัดการสินทรัพย์ไอที (IT Asset Management) และการตรวจสอบลิขสิทธิ์ซอฟต์แวร์แบบเดิมต้องอาศัยการเดินตรวจนับทีละเครื่องหรือใช้สคริปต์คำสั่งพื้นฐาน ส่งผลให้เกิดความล่าช้าและข้อมูลไม่เป็นปัจจุบัน โดยสรุปปัญหาหลักที่พบได้ดังนี้:

1. ภาระงานตรวจนับด้วยแรงคนสูง

การเก็บสเปกฮาร์ดแวร์และรายชื่อโปรแกรมกว่า 200 เครื่องใช้เวลา 3–5 วันทำการ เสี่ยงต่อความคลาดเคลื่อนจากการกรอกข้อมูลมือ

2. เครื่องปิด (Offline) ทำข้อมูลแหว่ง

สคริปต์ทั่วไปเมื่อพบเครื่องปิดหรือ Ghost DNS จะบันทึกเป็นค่าว่าง ทับข้อมูลเดิมสูญหาย และไม่ทราบประวัติการสแกนย้อนหลัง

3. ซอฟต์แวร์ตกค้างไม่ตรงความจริง

เมื่อผู้ใช้ถอนการติดตั้งโปรแกรมออก ฐานข้อมูลแบบรวมไฟล์เดิมไม่ลบรายการเก่าออก ทำให้ยอดลิขสิทธิ์ซอฟต์แวร์คลาดเคลื่อน

02
วัตถุประสงค์ของโครงงาน Project Objectives
1
พัฒนาระบบสแกนข้อมูลแบบไร้เอเจนต์ (Agentless Discovery): จัดเก็บข้อมูลฮาร์ดแวร์ ซอฟต์แวร์ พื้นที่ดิสก์ Uptime และโครงสร้าง Active Directory OU ของเครื่องลูกข่ายกว่า 200 เครื่องพร้อมกันผ่าน Multi-Thread RunspacePool
2
ออกแบบฐานข้อมูลหลักสะสมประวัติ (Master Database Upsert & Sync): คงข้อมูลเครื่องที่ออฟไลน์ไว้ในสถานะ Offline (Was OK) พร้อมซิงค์ลบรายชื่อโปรแกรมที่ถูกถอนการติดตั้งออกจากฐานข้อมูลหลักอัตโนมัติในรอบสแกนถัดไป
3
สร้างระบบตั้งเวลาสแกนอัตโนมัติและสแกนซ้ำเฉพาะเครื่องออฟไลน์: รองรับทั้ง In-App Countdown, Windows Task Scheduler (-Silent) และปุ่ม Retry Offline Only เพื่อลดเวลาการทำงานซ้ำซ้อน
4
ยกระดับความปลอดภัยและส่วนติดต่อผู้ใช้ระดับองค์กร: คอมไพล์เป็น Native C# Binary พร้อมลายเซ็นดิจิทัล Authenticode SHA-256 ปลอดการแจ้งเตือน Antivirus และแสดงผลผ่าน Modern Glassmorphism Dashboard

งานวิจัยและทฤษฎีที่เกี่ยวข้อง Related Research & Literature
ITAM Standard • ISO/IEC 19770

การบริหารสินทรัพย์ไอทีและลิขสิทธิ์ซอฟต์แวร์

มาตรฐาน ISO/IEC 19770 ระบุว่าการจัดทำบัญชีฮาร์ดแวร์-ซอฟต์แวร์ที่เป็นปัจจุบันช่วยลดต้นทุนการจัดซื้อซ้ำซ้อนได้ 15–30% และลดความเสี่ยงจากการตรวจสอบลิขสิทธิ์ (Software Audit)

Remote Telemetry • WMI / WinRM

สถาปัตยกรรมไร้เอเจนต์ (Agentless Architecture)

การศึกษาเปรียบเทียบชี้ว่าระบบ Agentless ผ่านโปรโตคอลมาตรฐาน Windows (WinRM 5985 และ DCOM WMI 135) ลดภาระการบำรุงรักษาและไม่กินทรัพยากรเครื่องลูกข่ายเมื่อเทียบกับ Agent-based

Concurrency • RunspacePool

การประมวลผลแบบคู่ขนานหลายเธรด

การใช้ PowerShell RunspacePool แทนการวนลูปแบบลำดับ (Sequential) ช่วยลด I/O Network Latency ของการรอตอบสนองจากเครื่องลูกข่าย ทำให้เพิ่มความเร็วสแกนเครือข่ายได้มากกว่า 10–15 เท่า

Endpoint Security • Authenticode

ลายเซ็นดิจิทัลและความน่าเชื่อถือของซอฟต์แวร์

การใช้ Native C# Launcher ร่วมกับใบรับรอง Authenticode SHA-256 และ UAC Manifest ช่วยยืนยันตัวตนผู้ผลิตและลดปัญหา False-Positive จากระบบป้องกันไวรัส (EDR/Defender)

บทสรุป & ข้อเสนอแนะ Conclusion & Recommendations

บทสรุปผลสัมฤทธิ์ของโครงงาน

  • ใช้งานได้จริงในสถานประกอบการ: ลดระยะเวลาการสำรวจเครื่องลูกข่ายกว่า 200 เครื่องจาก 3–5 วัน เหลือเพียงไม่ถึง 5 นาที
  • ข้อมูลแม่นยำและเป็นปัจจุบันเสมอ: Master Database รักษาประวัติเครื่องออฟไลน์ พร้อมอัปเดตและลบซอฟต์แวร์ที่ถูกถอนออกอัตโนมัติ
  • ปลอดภัยและพร้อมส่งมอบ: ไฟล์เดี่ยวขนาด 760 KB ลงนามดิจิทัล SHA-256 และตั้งเวลาสแกนอัตโนมัติผ่าน Windows Task Scheduler ได้ทันที

ข้อเสนอแนะเพื่อการพัฒนาต่อยอด

  • Centralized Web API & Database: พัฒนาการเชื่อมต่อกับฐานข้อมูลส่วนกลาง (SQL Server / PostgreSQL) เพื่อรองรับการสแกนข้ามสาขา
  • CVE Vulnerability Matching: เชื่อมต่อฐานข้อมูลช่องโหว่ (NVD/CVE) เพื่อแจ้งเตือนซอฟต์แวร์เวอร์ชันเก่าที่มีความเสี่ยงด้านไซเบอร์
  • Alert & ITSM Integration: เพิ่มการแจ้งเตือนอัตโนมัติผ่าน Microsoft Teams / LINE และเปิด Ticket ซ่อมบำรุงเมื่อดิสก์ใกล้เต็ม
