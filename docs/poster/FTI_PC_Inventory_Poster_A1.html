ภาระงานตรวจนับด้วยแรงคน

การเดินสำรวจสเปก PC กว่า 200 เครื่องในองค์กรใช้เวลา 3-5 วันทำการ เสี่ยงต่อข้อผิดพลาดและการทำงานซ้ำซ้อน

ข้อมูลฮาร์ดแวร์กระจัดกระจาย

ไฟล์ Excel เก่า ขาดการอัปเดตแบบเรียลไทม์ ไม่ทราบประวัติการเปลี่ยนแรม ซีพียู หรือฮาร์ดดิสก์ของเครื่องลูกข่าย

เครื่องปิด (Offline) ทำข้อมูลแหว่ง

สคริปต์ทั่วไปเมื่อเครื่องออฟไลน์จะบันทึกค่าว่าง ทับสเปกเดิมสูญหาย หรือติดปัญหา Ghost DNS ข้อมูลผิดพลาด

นวัตกรรม FTI PC Inventory

สแกนคู่ขนานแบบไร้เอเจนต์ ผสาน Master Database สะสมประวัติ ปลอดภัยด้วยลายเซ็นดิจิทัลระดับองค์กร

02
วัตถุประสงค์และขอบเขตทางเทคนิค Objectives & Scope
✓
สแกนข้อมูลอัตโนมัติแบบไร้เอเจนต์ (Agentless Architecture) : ดึงข้อมูลฮาร์ดแวร์ ซอฟต์แวร์ และสถานะ Active Directory ของเครื่องลูกข่ายในโดเมนกว่า 200 เครื่อง โดยไม่ต้องติดตั้งโปรแกรมดักฟังใดๆ บนเครื่องปลายทาง
✓
ระบบฐานข้อมูลหลักสะสมประวัติ (Master Database Cumulative Upsert) : อัปเดตข้อมูลเครื่องเดิมโดยไม่ลบทิ้ง คงประวัติเครื่องออฟไลน์ไว้ (Offline - Was OK) พร้อมบันทึกรอบนับ Scan_Count และเวลา First_Seen, Last_Scan
✓
ระบบตั้งเวลาอัตโนมัติแบบไฮบริด (Hybrid Automated Scheduling) : รองรับทั้งการนับถอยหลังภายในแอป (In-App Countdown) และการผสาน Windows Task Scheduler รันเบื้องหลังแบบไร้หน้าต่าง (-Silent) ทุกวัน
✓
วิศวกรรมความปลอดภัยมาตรฐานองค์กร (Enterprise Security & Trust) : คอมไพล์ด้วย .NET Framework Native C# ลงนามใบรับรองดิจิทัล Authenticode SHA-256 ป้องกันการแจ้งเตือนจาก Antivirus และ Windows SmartScreen 100%

Master DB Cumulative Upsert

ผสานข้อมูลอัตโนมัติ ไม่ลบข้อมูลเครื่องเดิม คงสเปกเครื่องออฟไลน์ไว้ พร้อมนับจำนวนครั้งที่เคยสแกนสำเร็จ

สแกนซ้ำเฉพาะเครื่องออฟไลน์

ปุ่ม "Retry Offline Only" สแกนซ้ำเฉพาะเครื่องที่เคยไม่ตอบสนอง ประหยัดเวลาแอดมินมากกว่า 85%

ตั้งเวลาสแกนอัตโนมัติไฮบริด

รองรับการนับถอยหลังในแอป และฝัง Task Scheduler ของ Windows รันเบื้องหลังแบบไร้หน้าต่าง (Silent Mode)

ตรวจจับฮาร์ดแวร์ & AD เชิงลึก

แสดงเวลา Uptime, โครงสร้างแผนก OU ลำดับชั้น, เวลาล็อกออนล่าสุดในโดเมน, และแถบเตือนพื้นที่ดิสก์ใกล้เต็ม

ออกรายงานหลากหลายรูปแบบ

ส่งออกไฟล์สรุป 9 CSV วิเคราะห์สถิติ และสร้าง Executive HTML Dashboard แยกกล่องค้นหารายเครื่องได้ทันที

บทสรุปและแนวทางการพัฒนาต่อยอด (Conclusions & Future Work)
