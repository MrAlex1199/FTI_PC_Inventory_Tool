01
ความเป็นมา & ปัญหาที่พบ Background & Problems

บริษัท ฟังก์ชั่น อินเตอร์เนชั่นแนล จำกัด (Function International - FTI) ทุนจดทะเบียน 225 ล้านบาท ดำเนินธุรกิจการผลิต นำเข้า และขายส่งผลิตภัณฑ์ที่เกี่ยวกับน้ำอย่างครบวงจร มีเครื่องคอมพิวเตอร์ลูกข่ายในโดเมน Active Directory กว่า 200 เครื่อง การตรวจนับทรัพย์สินไอทีและลิขสิทธิ์ซอฟต์แวร์แบบเดิมต้องเดินตรวจสอบด้วยคนหรือรันสคริปต์พื้นฐาน ทำให้เกิดปัญหาหลักดังนี้:

1. ภาระงานตรวจนับด้วยแรงคนสูง

การเก็บสเปกฮาร์ดแวร์และซอฟต์แวร์กว่า 200 เครื่องใช้เวลา 3–5 วันทำการ และเสี่ยงผิดพลาดจากการกรอกข้อมูลมือ

2. เครื่องปิด (Offline) ทำข้อมูลแหว่ง

สคริปต์ทั่วไปเมื่อเจอเครื่องปิดหรือ Ghost DNS จะเขียนทับเป็นค่าว่าง ทำให้ประวัติฮาร์ดแวร์เดิมสูญหาย

3. ซอฟต์แวร์ตกค้างไม่ตรงความจริง

เมื่อผู้ใช้ถอนโปรแกรมออก ไฟล์รวมเดิมไม่ลบรายการเก่า ทำให้ยอดตรวจสอบลิขสิทธิ์ซอฟต์แวร์คลาดเคลื่อน

แนวทางแก้ไข: FTI PC Inventory Tool

สแกนคู่ขนานไร้เอเจนต์ 30 Threads พร้อม Master DB สะสมประวัติ + ลบโปรแกรมที่ถอนออกอัตโนมัติ + เซ็น SHA-256

02
วัตถุประสงค์ของโครงงาน Project Objectives
1
พัฒนาระบบสแกนข้อมูลไร้เอเจนต์ (Agentless Discovery): จัดเก็บฮาร์ดแวร์ ซอฟต์แวร์ พื้นที่ดิสก์ Uptime และโครงสร้าง AD OU ของเครื่องลูกข่ายกว่า 200 เครื่องพร้อมกัน
2
ออกแบบ Master Database Upsert & Auto-Prune: คงสเปกเครื่องออฟไลน์ไว้ในสถานะ Offline (Was OK) พร้อมซิงค์ลบโปรแกรมที่ถูกถอนออกอัตโนมัติ
3
สร้างระบบตั้งเวลาอัตโนมัติและสแกนซ้ำเครื่องออฟไลน์: รองรับ In-App Countdown, Windows Task Scheduler (-Silent) และปุ่ม Retry Offline Only
4
ยกระดับความปลอดภัยและ UX ระดับองค์กร: คอมไพล์ Native C# Binary ลงนาม Authenticode SHA-256 ปลอดการแจ้งเตือน Antivirus พร้อมแดชบอร์ดเรียลไทม์

บทสรุปผลสัมฤทธิ์ของโครงงาน

  • ลดเวลาทำงานจริง 99.6%: สำรวจเครื่องลูกข่ายกว่า 200 เครื่องจาก 3–5 วัน เหลือเพียง 4.2 นาที
  • ข้อมูลแม่นยำเป็นปัจจุบัน: Master DB เก็บประวัติเครื่องออฟไลน์และลบซอฟต์แวร์ที่ถอนออกอัตโนมัติ

  • Centralized Web API & DB: เชื่อมต่อ SQL Server / PostgreSQL ส่วนกลางเพื่อรองรับการสแกนข้ามสาขา
  • CVE Vulnerability Scanner: จับคู่เวอร์ชันซอฟต์แวร์กับฐานข้อมูลช่องโหว่ (NVD/CVE) เพื่อแจ้งเตือนความเสี่ยง
  • Alert & ITSM Integration: แจ้งเตือนผ่าน Microsoft Teams / LINE และเปิด Ticket ซ่อมบำรุงอัตโนมัติ
